# playefeekids

## Baixar os dados da landing page (JSON)

O arquivo `play-e-fe-kids-dados.json`, na raiz deste repositório, contém todos os
dados exibidos na landing page (textos, depoimentos, bônus, benefícios, tema).

Como baixar direto do GitHub, sem precisar do site publicado:

1. Acesse a página do arquivo no GitHub:
   `https://github.com/agenciainovartconteudos-design/playefeekids/blob/main/play-e-fe-kids-dados.json`
2. Clique no botão **"Raw"** (ou **"Download raw file"**) no canto superior direito do visualizador do arquivo.
3. Use "Salvar como" no navegador (Ctrl+S / Cmd+S) para salvar o `.json` no seu computador.

Alternativa rápida (conteúdo bruto direto, sem abrir a interface do GitHub):
`https://raw.githubusercontent.com/agenciainovartconteudos-design/playefeekids/main/play-e-fe-kids-dados.json`

O mesmo conteúdo também pode ser baixado pelo site publicado, na página `/dados`
(link "Baixar dados" no menu do topo), que baixa o arquivo automaticamente ao abrir.
